# Tempus 产品 Roadmap

## 产品定位

**小而美的个人工时记录工具**，强调视觉享受和趣味性。

| 维度 | 定位                                 |
| ---- | ------------------------------------ |
| 用户 | 个人独立使用                         |
| 数据 | 本地存储 + 公司 REST API 同步        |
| 体验 | 视觉享受优先，精美动效和可视化       |
| 特色 | 成就系统（勋章、习惯养成、趣味称号） |

---

## Roadmap 概览

```
Phase 1: 趣味核心（MVP）     ──► 先让记录有动力
Phase 2: 数据基础           ──► 打通数据流
Phase 3: 可视化分析         ──► 看见自己的时间
Phase 4: 体验打磨           ──► 小而美的细节
```

## Phase 1: 趣味核心（MVP）

> 目标：让工时记录变得有趣，用户有动力打开应用

### 1.1 成就系统框架

- 成就数据模型设计（类型、条件、进度、解锁状态）
- 成就检测引擎（监听工时变化，自动判定解锁）
- 成就通知弹窗（解锁时的惊喜动效）

### 1.2 勋章体系（插画风格）

**里程碑勋章**

- 新手上路（首次记录）
- 百小时俱乐部 / 500小时 / 1000小时
- 月度满勤

**习惯养成勋章**

- 连续打卡 7/30/100 天
- 准时下班达人（连续N天不加班）
- 早起鸟（连续N天9点前到岗）

**特殊成就勋章**

- 深夜战士（22点后还在工作）
- 周末勇士（周末加班）
- 节日坚守（法定节假日加班）
- 极限挑战（单日工时超过12小时）

### 1.3 勋章展示页

- 勋章墙（已解锁/未解锁状态）
- 勋章详情（获得时间、稀有度、描述）
- 进度条（距离下一个勋章还差多少）

### 1.4 基础工时录入

- 简单的工时输入表单（日期、上班时间、下班时间）
- 当日工时卡片展示
- 本地存储（先用 localStorage 或 JSON 文件）

### 1.5 实时收入卡片

> 把工时转化为"收入"的趣味可视化

**核心概念**

- 设置时薪（如 100元/小时）
- 实时显示今日已工作时长 → 已赚金额
- **加班惩罚机制**：超过 8 小时后，时薪递减（如每多 1 小时，时薪 -10%），最终可能"亏钱"

**动画效果**（任选其一或组合）

- 水位线动画：随时间上涨，加班过度后水变红/溢出
- 沙漏动画：沙子流动表示时间流逝
- 金币堆积：每小时掉落金币，加班后金币变灰/破碎
- 进度环：圆环填充，超时后变色

**展示信息**

- 今日已工作：`5h 23m`
- 今日收入：`¥523`（实时滚动数字）
- 时薪状态：`正常 ¥100/h` / `递减中 ¥80/h` / `已亏损`

### 1.6 趣味统计卡片

- 本周最晚下班日
- 本月加班王日期
- 连续早起天数
- "今日已超越 80% 的自己"

## Phase 2: 数据基础

> 目标：打通数据来源，建立可靠的数据层

### 2.1 本地数据持久化

- 选型：SQLite（通过 better-sqlite3）或 JSON 文件
- 工时记录表结构设计
- 成就记录表结构设计
- 数据迁移方案

### 2.2 公司 API 对接

- API 配置页面（接口地址、认证方式）
- 数据拉取与本地合并逻辑
- 增量同步 vs 全量同步
- 错误处理与重试机制

### 2.3 数据管理

- 数据导出（JSON/CSV）
- 数据导入（历史数据迁移）
- 数据备份与恢复

---

## Phase 3: 可视化分析

> 目标：用精美的图表展示工时数据

### 3.1 时间趋势分析

- 日工时柱状图（本周/本月）
- 周工时趋势折线图
- 月度工时热力图（类似 GitHub 贡献图）

### 3.2 对比分析

- 与标准工时对比（8小时基准线）
- 周环比 / 月同比
- 加班时长统计

### 3.3 日历视图增强

- 在现有日历上显示每日工时
- 颜色深浅表示工时长短
- 点击查看当日详情

### 3.4 图表库选型

- 推荐：Recharts 或 ECharts
- 统一的图表主题（配合深色/浅色模式）

---

## Phase 4: 体验打磨

> 目标：小而美的细节体验

### 4.1 动效优化

- 页面切换过渡动画
- 数据加载骨架屏
- 勋章解锁庆祝动效（confetti/粒子效果）
- 数字滚动动画

### 4.2 系统集成

- 系统托盘图标
- 托盘菜单（快速记录、查看今日工时）
- 开机自启动选项

### 4.3 提醒功能

- 下班提醒（可配置时间）
- 每日工时统计推送
- 成就即将解锁提醒

### 4.4 主题与个性化

- 深色/浅色模式切换
- 主题色自定义
- 勋章展示顺序自定义

## 技术选型建议

| 领域     | 推荐方案                                 |
| -------- | ---------------------------------------- |
| 本地存储 | better-sqlite3 或 electron-store（JSON） |
| 图表     | Recharts（React 友好）或 ECharts         |
| 动效     | motion/react（已引入） + canvas-confetti |
| 状态管理 | Zustand（轻量）或 Jotai                  |
| HTTP     | ky 或 axios                              |

## 验证方式

**Phase 1 完成标准**：

- 能手动录入工时
- 录入后自动检测并解锁对应成就
- 成就墙页面能展示所有勋章状态
- 实时收入卡片能正常显示和动画

**运行验证**：`pnpm dev` 启动应用，测试完整流程
